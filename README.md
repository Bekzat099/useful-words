# Useful Words — EN → RU / KZ

Сайт для изучения слов из списка **Medium Level Wordlist V2.0** (1036 слов).

- **Слова** — весь список в исходном порядке: английское слово + перевод на русский и казахский. Есть поиск.
- **Карточки** — флеш-карточки: на лицевой стороне английское слово, на обороте перевод на русский и казахский. Навигация стрелками, слайдером или тапом по карточке.
- **Проверка** — самодиагностика: выбираешь, сколько первых слов проверить (10 / 25 / 50 / 100 / 200 / 300 / 500 / все / своё число). Отвечаешь «Знал / Не знал», в конце — результат в процентах, список пропущенных слов и кнопка «Повторить ошибки».

Простой статический сайт (HTML/CSS/JS, без зависимостей). Размещён на GitHub Pages.
